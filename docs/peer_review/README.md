# Peer Review

Each of the eight GCI subindices was reviewed by external scholars with subject
expertise in that domain. Reviewers assessed the theoretical justification for
the subindex, the appropriateness of its domain structure, and the merit of each
dataset selected as an input.

Each of the reviews and our responses to them are posted here for public reference. Where a review prompted a change to the
index, the change is reflected in the current release and described in both the response and the 
accompanying academic paper.
